# Các nhóm câu lệnh SQL
| Nhóm | Chức năng              | Ví dụ                       |
| ---- | ---------------------- | --------------------------- |
| DDL  | Định nghĩa cấu trúc DB | CREATE, ALTER, DROP         |
| DML  | Thao tác dữ liệu       | INSERT, UPDATE, DELETE      |
| DCL  | Quyền / bảo mật        | GRANT, REVOKE               |
| TCL  | Quản lý transaction    | COMMIT, ROLLBACK, SAVEPOINT |
| DQL  | Truy vấn dữ liệu       | SELECT                      |


| Loại             | Mục đích                                |  Nhóm      |
| ---------------- | --------------------------------------- | -------------- |
| Stored Procedure | Tạo logic thực thi nhiều SQL            | Procedural SQL <Thủ tục>|
| Function         | Trả giá trị hoặc bảng, dùng trong query | Procedural SQL <Thủ tục>|
| Trigger          | Tự động chạy khi có event trên bảng     | Procedural SQL <Thủ tục>|
